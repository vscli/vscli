# Native directional-neighbor query foundation

`Layout::neighbor_candidates` returns up to four existing groups on the requested logical boundary. Checked rational intervals follow the retained tree's integer weights; strict positive perpendicular overlap excludes corner-only contact. Outer-edge wrapping preserves that interval. The query changes no layout identity, counters, membership, text or pointer authorization and performs no dynamic result allocation.

Visual one-cell dividers have zero area in this logical query. Terminal minimum-size clamps/flooring and upstream CSS pixel rounding can produce different adjacency; pixel-equivalent navigation is unqualified. The read-only query is separate from the later App focus command and its MRU tie-break. No user-visible command or terminal input changes are introduced by this foundation alone.

Eight spatial tests plus 25 existing layout/App/UI tests pass, including weighted/deep/extreme bounds, strict corners, wrapping, malformed private trees, arithmetic/counter refusal, and retained tiny geometry. Formatting and strict locked all-target Clippy pass. App commands/profile bindings, real save-close ownership and PTY evidence remain separate integration work.
