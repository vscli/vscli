# VSCLI 0.1.0 — development alpha

Native terminal editing with multiple cursors, split views, workspace search, language-server integration, terminal sessions, tasks, Git workflows, and initial debugger support. Includes crash recovery, live file updates, grammar highlighting, and a limited VS Code settings/keybinding import.

This is an alpha, not full VS Code compatibility. Extension execution, rich webviews/notebooks, complete keybinding behavior, and several advanced editing/IDE workflows remain incomplete. See `docs/USAGE.md` and `docs/RELEASE_CHECKLIST.md` for the current contract.

Archives contain the executable, usage documentation, build information, dependency inventory, and available upstream license notices. Verify the adjacent SHA-256 checksum before extracting. macOS binaries are not signed/notarized; terminal and OS qualification is tracked separately from build success.
